# ToyForge 3D v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the ToyForge 3D kid builder, class-code submission server, teacher dashboard, and nginx/Docker deployment for `toyforge.chupa.nexus`.

**Architecture:** npm-workspaces monorepo. `packages/shared` holds every rule both sides enforce (names, class codes, recipe schema, filenames, API types). `apps/server` is one Fastify process (API + static files + hourly retention job) over SQLite and files on disk. `apps/web` is a Vite multi-page vanilla-TS app (builder, teacher, privacy) with bundled Three.js, Tailwind, Fredoka and Lucide icons, localised en/cs/pl.

**Tech Stack:** Node 22 LTS (dev on 24 ok), TypeScript 5, Fastify 5 (+ @fastify/multipart, @fastify/static, @fastify/rate-limit), better-sqlite3, archiver, zod 4, Vite 8, Tailwind 4 (@tailwindcss/vite), three 0.187, lucide, qrcode, idb, @fontsource/fredoka, Vitest, fake-indexeddb, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-23-toyforge-design.md`

## Global Constraints

- No Angular. Vanilla TS by default; Vue or React only if needed.
- No runtime CDN or third-party requests: fonts, icons, Three.js, Tailwind all bundled.
- Maker nickname 1–20 chars (required); character name 0–24 (empty → `"Untitled Creature"` server-side); class name 0–40. Allowed: Unicode letters, digits, space, `-`, `_`, `'`.
- Class code: 6 chars from `ABCDEFGHJKMNPQRSTUVWXYZ`; input case-insensitive, spaces/dashes ignored; displayed `KQM TRB`.
- Teacher key: 32 random bytes base64url, shown once, stored as sha256 hex; link `${PUBLIC_URL}/teacher#key=<key>`; sent as `Authorization: Bearer`.
- Limits: request ≤ 10 MB (nginx 12m), STL ≤ 10 MB, `84 + 50·n == length`, `1 ≤ n ≤ 200 000`; thumbnail PNG ≤ 2 MB, ≤ 1024×1024; recipe JSON ≤ 32 KB; ≤ 500 models/class.
- Rate limits: submissions 60/min/IP + 300/h/class; class create 10/h/IP; code lookup 60/min/IP; teacher 300/min/key; failed bearer 20/min/IP.
- Retention: delete classes with `last_activity_at` older than `RETENTION_DAYS` (30); expired = 404 immediately.
- Print statuses: `new | queued | printed` only.
- Languages `en` (fallback), `cs`, `pl`; detection `?lang=` → localStorage → `navigator.languages` → `en`. No hard-coded user-facing text.
- WebGL2 required; otherwise localised "device can't run ToyForge" screen.
- Never render user strings via `innerHTML`.
- STL export: clone character group, rotate +90° X, scale ×10, binary. Download name `{maker}_{character}_{YYYYMMDD}.stl`; server/ZIP name `{maker}_{character}_{id[0..4]}.stl`; ASCII-folded slugs.
- Thumbnail ≤ 512×512 PNG.
- Error JSON: `{ "error": ErrorCode, "message": string }`.

## Review Focus

1. **Polish/Czech letters in names** (`Łukasz`, `Šimon`, `Žofie`) must be accepted and fold to `lukasz`, `simon`, `zofie` in filenames — NFD does not decompose `ł`. Pinned in Task 1.
2. **Lost response, retried upload** — the same `submissionId` re-sent must return 200 and the existing record, never a duplicate card. Pinned in Task 3 and Task 9.
3. **Class expires or closes while a model sits in the offline queue** — the item must stop retrying, show the reason, and remain downloadable. Pinned in Task 9.
4. **Two kids with identical nickname + character name** in one ZIP — both files must be present with distinct names. Pinned in Task 4.
5. **Whole classroom behind one NAT IP** — 30 kids sending within a minute must all succeed. Pinned in Task 3.
